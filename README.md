# Materiały dydaktyczne

Projekty do realizacji, karty pracy i materiały pomocnicze dla uczniów i studentów.

## Wybierz placówkę

- [ZSEM](ZSEM/README.md)
- [PTI](PTI/README.md)

## Jak korzystać

1. Wybierz placówkę.
2. Otwórz folder swojej klasy.
3. Wybierz przedmiot i odpowiedni temat lub projekt.
4. Zapoznaj się z instrukcją zadania, terminem i sposobem oddania pracy podanymi w jego materiałach.

## Układ materiałów

**PLACÓWKA / Klasa / Przedmiot**

Skróty placówek zapisujemy dużymi literami. Materiały nie są podzielone według roku szkolnego, dzięki czemu mogą służyć kolejnym rocznikom. Projekty i materiały znajdują się w folderach przedmiotów.

Karty pracy są dostępne w folderach przedmiotów jako pliki DOCX. Kliknij link „pobierz DOCX”, aby pobrać wybraną kartę.
