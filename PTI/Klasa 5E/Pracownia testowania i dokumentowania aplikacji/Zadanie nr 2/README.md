# Publikacja testów i dokumentacji w GitHub

*Następstwo karty pracy 03 | Pracownia testowania i dokumentowania aplikacji*

**INF.04 | Praca własna ucznia | Klasa 5E | PTI**

## Cel zadania

Dodaj dokumentację testów aplikacji konsolowej i mobilnej do istniejącego publicznego repozytorium. Nie twórz nowego repozytorium.
## Wymagana nazwa repozytorium

Użyj schematu:

`XX_YY_5E_PTI`
- XX – dwie pierwsze litery nazwiska;
- YY – dwie pierwsze litery imienia;
- polskie znaki zastąp odpowiednikami bez znaków diakrytycznych;
- nie umieszczaj pełnego imienia i nazwiska w nazwie repozytorium ani publicznym README.
## Wymagana struktura repozytorium

`XX_YY_5E_PTI/01_obiektowe/
XX_YY_5E_PTI/02_mobilne/
XX_YY_5E_PTI/03_testy_dokumentacja/`
## Zawartość folderu 03_testy_dokumentacja

- egzamin.docx;
- folder zrzuty;
- konsola1.png i konsola2.png;
- mobilna1.png i mobilna2.png.
Dokument egzamin.docx

dane ucznia, klasa i data;
system operacyjny, środowisko i język;
opis czynności, oczekiwany i rzeczywisty rezultat;
status PASS albo FAIL;
wnioski z testów.
### Wymagane testy

- Utworzenie pierwszej notatki w aplikacji konsolowej.
- Utworzenie drugiej notatki i uruchomienie metod.
- Sprawdzenie licznika i identyfikatorów.
- Uruchomienie aplikacji mobilnej.
- Dodanie notatki Urodziny Ali.
Dodanie drugiej własnej notatki.
## Pliki, których nie należy publikować

Przed zatwierdzeniem zmian obowiązkowo usuń pliki tymczasowe i wynikowe:

`.vs/   bin/   obj/   Debug/   Release/   *.pdb   *.user   *.suo`
Nie usuwaj plików potrzebnych do otwarcia, kompilacji i uruchomienia projektu.

## Procedura wykonania

1. Otwórz repozytorium zawierające 01_obiektowe i 02_mobilne.
2. Nie twórz nowego repozytorium.
3. Utwórz folder 03_testy_dokumentacja.
4. Przygotuj egzamin.docx na podstawie rzeczywistych testów.
5. Utwórz folder zrzuty i dodaj cztery wymagane zrzuty.
6. Sprawdź, czy dokument otwiera się bez błędów.
7. Usuń pliki tymczasowe i wynikowe.
8. Wykonaj commit: 03_testy_dokumentacja – testy i dokumentacja.
9. Opublikuj zmiany.
10. Sprawdź kompletne repozytorium w trybie incognito.
