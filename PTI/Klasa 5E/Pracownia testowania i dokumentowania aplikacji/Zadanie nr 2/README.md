# Publikacja testów i dokumentacji w GitHub

**Zadanie nr 2** · Pracownia testowania i dokumentowania aplikacji  
**INF.04 · Praca własna ucznia · Klasa 5E · PTI**

## Cel i struktura

Dodaj dokumentację testów aplikacji konsolowej i mobilnej do istniejącego publicznego repozytorium. Nie twórz nowego repozytorium.

Repozytorium musi zawierać: 01_obiektowe/, 02_mobilne/ oraz 03_testy_dokumentacja/ z plikiem egzamin.docx i folderem zrzuty zawierającym konsola1.png, konsola2.png, mobilna1.png i mobilna2.png.

## Procedura

1. Otwórz repozytorium zawierające 01_obiektowe i 02_mobilne.
2. Utwórz folder 03_testy_dokumentacja i przygotuj egzamin.docx na podstawie rzeczywistych testów.
3. Dodaj cztery wymagane zrzuty i sprawdź dokument.
4. Usuń .vs/, bin/, obj/, Debug/, Release/, *.pdb, *.user i *.suo.
5. Wykonaj commit: 03_testy_dokumentacja – testy i dokumentacja.
6. Opublikuj zmiany i sprawdź kompletne repozytorium w trybie incognito.
