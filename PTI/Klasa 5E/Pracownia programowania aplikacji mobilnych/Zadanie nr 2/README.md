# Publikacja aplikacji mobilnej w GitHub

*Następstwo karty pracy 02 | Pracownia programowania aplikacji mobilnych*

**INF.04 | Praca własna ucznia | Klasa 5E | PTI**

## Cel zadania

Dodaj kompletną aplikację NotatkiMobilne do publicznego repozytorium utworzonego podczas pierwszej karty pracy. Nie twórz nowego repozytorium.
## Wymagana nazwa repozytorium

Użyj schematu:

`XX_YY_5E_PTI`
- XX – dwie pierwsze litery nazwiska;
- YY – dwie pierwsze litery imienia;
- polskie znaki zastąp odpowiednikami bez znaków diakrytycznych;
- nie umieszczaj pełnego imienia i nazwiska w nazwie repozytorium ani publicznym README.
## Wymagania technologiczne

język C#;

technologia .NET MAUI;

interfejs XAML.

## Wymagana struktura repozytorium

`XX_YY_5E_PTI/01_obiektowe/ oraz XX_YY_5E_PTI/02_mobilne/`
## Zawartość folderu 02_mobilne

kompletny projekt .NET MAUI;

- plik .sln i .csproj;
pliki .cs i .xaml;

foldery Resources i Platforms;

App.xaml, AppShell.xaml i MauiProgram.cs;

mobilna1.png i mobilna2.png.
## Zrzuty ekranu

- mobilna1.png – cały ekran z emulatorem, środowiskiem i trzema początkowymi notatkami.
- mobilna2.png – cały ekran z emulatorem, środowiskiem i nową notatką na końcu listy.
## Pliki, których nie należy publikować

Przed zatwierdzeniem zmian obowiązkowo usuń pliki tymczasowe i wynikowe:

`.vs/   bin/   obj/   Debug/   Release/   *.pdb   *.user   *.suo`
Nie usuwaj plików potrzebnych do otwarcia, kompilacji i uruchomienia projektu.

## Procedura wykonania

Otwórz repozytorium z folderem 01_obiektowe.
Nie twórz nowego repozytorium.
Utwórz folder 02_mobilne.
Skopiuj do niego kompletny projekt NotatkiMobilne.
Usuń pliki tymczasowe i wynikowe.
Uruchom aplikację w emulatorze Androida.
Wykonaj mobilna1.png.
Dodaj notatkę, np. Urodziny Ali, i wykonaj mobilna2.png.
Wykonaj commit: 02_mobilne – projekt C# .NET MAUI NotatkiMobilne.
Opublikuj zmiany.
Sprawdź repozytorium w trybie incognito.
