# Mobilna lista notatek

**Pracownia programowania aplikacji mobilnych · INF.04 · Klasa 5E · PTI**

## Cel

Wykonaj prostą aplikację mobilną w C# i .NET MAUI. Aplikacja ma prezentować trzy notatki, umożliwiać dodawanie wpisów i automatycznie odświeżać listę.

## Zadanie

1. Utwórz projekt .NET MAUI App o nazwie NotatkiMobilne.
2. W XAML zastosuj układ pionowy oraz poziomy wiersz z polem edycyjnym i przyciskiem.
3. Dodaj tytuł, pole z podpowiedzią Nowy element i przycisk DODAJ.
4. Dodaj ListView albo CollectionView prezentujący kolekcję tekstową.
5. W C# utwórz ObservableCollection<string> z trzema własnymi notatkami.
6. Połącz kolekcję z widokiem listy.
7. Po kliknięciu DODAJ odczytaj tekst, dodaj go na końcu kolekcji i wyczyść pole.
8. Przetestuj wpis Urodziny Ali oraz drugą własną notatkę.
9. Ustaw tło przycisku Crimson (#DC143C) i biały tekst.
10. Skompiluj aplikację, uruchom ją w emulatorze i wykonaj mobilna1.png ze stanem początkowym oraz mobilna2.png po dodaniu wpisu.
