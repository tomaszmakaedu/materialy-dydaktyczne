# Publikacja projektu obiektowego w GitHub

**Następstwo karty pracy 01** · Pracownia projektowania obiektowego  
**INF.04 · Praca własna ucznia · Klasa 4E · PTI**

## Cel

Opublikuj kompletny projekt NotatkiKonsola w jednym publicznym repozytorium GitHub. To samo repozytorium będzie później wykorzystywane do aplikacji mobilnej i dokumentacji testów. Nie twórz trzech repozytoriów.

## Repozytorium i struktura

Nazwa: **XX_YY_4E_PTI**

XX – dwie pierwsze litery nazwiska; YY – dwie pierwsze litery imienia. Polskie znaki zastąp odpowiednikami bez znaków diakrytycznych. Nie umieszczaj pełnego imienia i nazwiska w nazwie repozytorium ani w publicznym README.

Wymagana struktura:

- 01_obiektowe/

Folder musi zawierać kompletny projekt Visual Studio NotatkiKonsola, plik .sln, plik .csproj, wszystkie pliki źródłowe .cs oraz zrzut konsola1.png.

Zrzut konsola1.png ma pokazywać cały ekran, pasek zadań, uruchomiony program, co najmniej dwie notatki, identyfikatory, działanie obu metod oraz kod albo terminal.

## Pliki zakazane

Obowiązkowo usuń przed publikacją:

.vs/ · bin/ · obj/ · Debug/ · Release/ · *.pdb · *.user · *.suo

Nie usuwaj plików potrzebnych do otwarcia, kompilacji i uruchomienia projektu.

## Procedura

1. Utwórz publiczne repozytorium XX_YY_4E_PTI.
2. Utwórz folder 01_obiektowe i skopiuj do niego kompletny projekt.
3. Usuń pliki tymczasowe i wynikowe.
4. Uruchom program i wykonaj konsola1.png.
5. Wykonaj commit: 01_obiektowe – projekt C# NotatkiKonsola.
6. Opublikuj zmiany i sprawdź repozytorium w trybie incognito.
