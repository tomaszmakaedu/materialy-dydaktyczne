# Publikacja testów i dokumentacji w GitHub

**Następstwo karty pracy 03** · Pracownia testowania i dokumentowania aplikacji  
**INF.04 · Praca własna ucznia · Klasa 4E · PTI**

## Cel i struktura

Dodaj dokumentację testów aplikacji konsolowej i mobilnej do istniejącego publicznego repozytorium. Nie twórz nowego repozytorium.

Repozytorium musi zawierać:

- 01_obiektowe/
- 02_mobilne/
- 03_testy_dokumentacja/
  - egzamin.docx
  - zrzuty/
    - konsola1.png
    - konsola2.png
    - mobilna1.png
    - mobilna2.png

## Dokument egzamin.docx

Dokument musi zawierać dane ucznia, klasę i datę, system operacyjny, środowisko i język, opis czynności, oczekiwany i rzeczywisty rezultat, status PASS albo FAIL oraz wnioski z testów.

## Wymagane testy

1. Utworzenie pierwszej notatki w aplikacji konsolowej.
2. Utworzenie drugiej notatki i uruchomienie metod.
3. Sprawdzenie licznika i identyfikatorów.
4. Uruchomienie aplikacji mobilnej.
5. Dodanie notatki Urodziny Ali.
6. Dodanie drugiej własnej notatki.

## Pliki zakazane

Usuń: .vs/, bin/, obj/, Debug/, Release/, *.pdb, *.user, *.suo. Nie usuwaj plików potrzebnych do otwarcia, kompilacji i uruchomienia projektu.

## Procedura

1. Otwórz repozytorium zawierające 01_obiektowe i 02_mobilne.
2. Utwórz folder 03_testy_dokumentacja.
3. Przygotuj egzamin.docx na podstawie rzeczywistych testów.
4. Utwórz folder zrzuty i dodaj cztery wymagane zrzuty.
5. Sprawdź dokument, usuń pliki tymczasowe i wynikowe.
6. Wykonaj commit: 03_testy_dokumentacja – testy i dokumentacja.
7. Opublikuj zmiany i sprawdź kompletne repozytorium w trybie incognito.
